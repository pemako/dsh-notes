# 便签 / Sticky notes

一个 DSH 小插件，在侧栏底部放一个「便签」入口，点开就是一块浮动的便签板。

## 安装

Plugins → Add plugin 里填：

```
@pemako/dsh-notes
```

想固定版本就在名字后面加 `@版本号`。

## 能做什么

便签正文是 Markdown。标题、粗体、斜体、删除线、行内代码、代码块、链接、列表、任务列表、引用、分隔线都认，原始 HTML 会当普通文字显示。

每张便签有一个紧急程度颜色，红、琥珀、绿、蓝、灰，点卡片上的小胶囊就能换。拖动右边、下边或者右下角可以改大小；手机上卡片占满宽度，只能调高度，在手机上新建的便签会记住这个宽度。

在用的便签按创建日期分组，归档过的按归档日期分组。面板上方的搜索框会同时查标题和正文。

输入时自动保存，数据存在浏览器的 localStorage 里，键名 `dsh-notes.notes.v1`。空草稿离开时会丢掉。

## 怎么用

点侧栏底部 Settings 上方的「便签」，再点「新建便签」写标题和正文。双击卡片，或者点「编辑」，继续改；点「完成」退出编辑。颜色胶囊用来标紧急程度，盒子图标归档，垃圾桶图标删除，删除要三秒内点第二次。归档标签页按日期列出已经归档的便签，点盒子图标可以恢复。

## 手机上

抽屉是 `dsh-web-mobile` 提供的时候，打开便签会先把侧栏抽屉收起来，便签浮在上面。便签固定在视口上，四周留 8px，层级在抽屉之上，关掉再打开抽屉不会把它盖住，也不会让它点不动。从便签里开始的滑动手势由便签自己处理，移动端滑动层看到 `data-mobile-nav-dragging` 标记会让开，所以调大小或者滚动便签不会误开抽屉和文件面板。

## 需要知道

便签存在创建它的那个浏览器配置里，不跨浏览器、设备或者 DSH profile 同步；停用插件也不会删掉已经存下的内容。

同时开两个 GUI 标签页时，便签按 id 合并，较新的副本优先。在一个标签页里删掉的便签，如果另一个标签页还留着，可能会重新出现。

浏览器不让用 localStorage 时，面板底部会提示没有保存，控制台里有具体的错误。读不出来的数据会在下次保存前备份到 `dsh-notes.notes.v1.backup`。

归档的便签在恢复之前不能改。

Markdown 表格、图片、原始 HTML、反斜杠转义和嵌套列表缩进都不支持。
